# Patient Monitor

A **Digital Health / Healthcare IT prototype** for monitoring patient vital signs through a web-based application.

The project currently simulates a wearable device that generates heart-rate data, exposes the data through a **FastAPI REST API**, and displays it through a **Next.js / React frontend**.

The application is being developed incrementally, with the long-term goal of exploring device data ingestion, persistence, healthcare interoperability and standards such as **HL7 and FHIR**.

> **Current status:** Initial prototype — local development and mock data.

---

## Overview

The project explores a simplified healthcare monitoring workflow:

```text
Mock Device
     ↓
FastAPI Backend
     ↓
REST API
     ↓
Next.js / React Frontend
     ↓
Patient / Doctor Dashboard
```

The current implementation focuses on establishing the basic communication between a simulated medical/wearable device, a backend API and a web interface.
